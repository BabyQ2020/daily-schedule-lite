这个页面只做一件事：在不写入任何数据的前提下，把浏览器里 daily-schedule-lite 数据库原样导出成 JSON，便于在升级、排查或删库前留底。

安全约束（代码层面保证）
  • 只使用 readonly 事务；页面内没有任何 add/put/delete/clear 调用。
  • 打开时显式指定当前版本；一旦触发 onupgradeneeded 立即中止事务，避免「打开就建库」。
  • 先通过 indexedDB.databases() 确认库存在；浏览器不支持该 API 时直接拒绝，不做猜测。
  • 导出格式是救援快照，不是可导入的备份格式。
什么时候用它

升级前留底、怀疑数据异常但主应用打不开、或准备在 DevTools 里删库前。导出的 JSON 建议按日期改名保存，例如 rescue-2026-11-19.json。
